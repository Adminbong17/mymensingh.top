# 🌿 Mymensingh.top - আমার শহর, আমাদের গাইড
### ময়মনসিংহ সিটি গাইড ও বিজনেস পোর্টাল (City Guide & Business Portal)

A modern, responsive, mobile-first Web Application and Admin Management Portal for **Mymensingh, Bangladesh**, powered by **React 19**, **Vite**, **Tailwind CSS**, and **Supabase**.

---

## 🚀 Quick Start

```bash
cd mymensingh-city-guide
npm install
npm run dev
```
Open **`http://localhost:5173`** in your browser.

---

## 🗄️ Supabase Database Setup

Open your Supabase project's SQL Editor, paste the contents of [`supabase_schema.sql`](./supabase_schema.sql), and click **Run**.
