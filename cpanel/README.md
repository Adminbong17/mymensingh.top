# Mymensingh.top - cPanel MySQL Backend Guide
(ময়মনসিংহ সিটি গাইড - সিপ্যানেল মাইএসকিউএল ডেটাবেজ সেটআপ গাইড)

এই ফোল্ডারে আপনার নিজস্ব **cPanel হোস্টিং ও MySQL ডেটাবেজে** ওয়েবসাইট চালানোর জন্য প্রয়োজনীয় সকল ফাইল প্রস্তুত করা আছে।

---

## 📁 ফাইল স্ট্রাকচার:
```text
cpanel/
├── database.sql           <-- phpMyAdmin এ ইমপোর্ট করার জন্য সম্পূর্ণ MySQL স্কিমা
├── README.md              <-- সেটআপ নির্দেশিকা
└── api/
    ├── config.php         <-- ডেটাবেজ সংযোগ ও কনফিগারেশন
    ├── index.php          <-- সকল CRUD ও লগইন/রেজিস্ট্রেশন API
    └── .htaccess          <-- Clean URL ও CORS পারমিশন
```

---

## 🚀 cPanel-এ সেটআপ করার ৪টি সহজ ধাপ:

### ধাপ ১: cPanel-এ MySQL ডেটাবেজ তৈরি করুন
1. আপনার cPanel-এ লগইন করুন।
2. **Databases** সেকশন থেকে **MySQL® Database Wizard**-এ ক্লিক করুন।
3. নতুন একটি ডাটাবেজের নাম দিন (যেমন: `mymensingh_db`) এবং **Next Step** চাপুন।
4. একজন নতুন ডাটাবেজ ব্যবহারকারী (User) তৈরি করুন এবং একটি শক্তিশালী পাসওয়ার্ড দিন। (পাসওয়ার্ডটি লিখে রাখুন)।
5. **ALL PRIVILEGES** অপশনে টিক চিহ্ন দিয়ে **Make Changes** চাপুন।

---

### ধাপ ২: phpMyAdmin এ টেবিলগুলো ইমপোর্ট করুন (`database.sql`)
1. cPanel হোমপেজে ফিরে গিয়ে **phpMyAdmin** ওপেন করুন।
2. বাম পাশের মেনু থেকে মাত্র তৈরি করা আপনার ডেটাবেজটির ওপর ক্লিক করুন।
3. উপরের মেনুবার থেকে **Import** ট্যাবে ক্লিক করুন।
4. **Choose File**-এ ক্লিক করে এই ফোল্ডারের `database.sql` ফাইলটি নির্বাচন করুন।
5. পেজের নিচের দিকে গিয়ে **Import / Go** বাটনে ক্লিক করুন।
> 🎉 সাথে সাথে ১০টি টেবিল (ব্যবসায়িক প্রতিষ্ঠান, সংবাদ, ইভেন্ট, অফার, রক্তদাতা, টিউশন, টু-লেট, রিভিউ, ইউজার) স্বয়ংক্রিয়ভাবে তৈরি হয়ে যাবে!

---

### ধাপ ৩: `api/config.php` ফাইলটিতে আপনার ডেটাবেজের তথ্য দিন
`cpanel/api/config.php` ফাইলটি যেকোনো কোড এডিটরে ওপেন করে লাইন ২০-২৩ এ আপনার cPanel ডেটাবেজের তথ্য বসিয়ে দিন:

```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'আপনার_cpanel_ইউজারনেম_mymensingh_db');
define('DB_USER', 'আপনার_cpanel_ইউজারনেম_dbuser');
define('DB_PASS', 'আপনার_ডাটাবেজ_পাসওয়ার্ড');
```

---

### ধাপ ৪: cPanel ফাইল ম্যানেজারে আপলোড করুন
1. cPanel থেকে **File Manager** ওপেন করুন।
2. **`public_html`** ফোল্ডারে প্রবেশ করুন।
3. `api` ফোল্ডারটি সরাসরি `public_html/`-এর ভেতরে আপলোড করে দিন।
   - পাথটি দেখতে এমন হবে: `public_html/api/`
4. ব্রাউজারে চেক করুন:
   👉 `https://আপনার-ডোমেইন.com/api/` অথবা `https://আপনার-ডোমেইন.com/api/index.php`
   - যদি `{ "success": true, "businesses": [...] }` দেখতে পান, তবে আপনার API ১০০% লাইভ ও প্রস্তুত!
